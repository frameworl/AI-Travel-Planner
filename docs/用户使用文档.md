# Web 版 AI 旅行规划师（AI Travel Planner）用户使用文档

版本：v0.1 文档草案（产品原型阶段）

## 1. 产品简介
AI 旅行规划师旨在简化旅行规划流程，通过语音或文字输入您的出行需求，自动生成个性化的旅行路线和建议，并提供预算管理与云端同步，帮助您在多设备上随时查看与调整行程。

## 2. 适用场景
- 快速获得目的地行程建议（交通、住宿、景点、餐厅）。
- 家庭或多人同行的行程协同与偏好适配。
- 行程期间的费用记录与预算提醒（支持语音输入）。
- 地图导航下的日程与位置联动。

## 3. 快速上手
1) 打开 Web 应用并登录/注册账号：用于保存规划与云端同步。
2) 开启麦克风权限：让语音输入可用（也可改用文字输入）。
3) 创建行程：输入目的地、日期、预算、人数与偏好（如“我想去日本，5 天，预算 1 万元，喜欢美食和动漫，带孩子”）。
4) 查看与调整：系统生成的路线包含每日安排、交通、住宿与餐饮建议，可在地图中查看位置与导航。
5) 记录费用：旅行期间可语音或文字快速记录开销并查看预算占用情况。

## 4. 核心功能说明
### 4.1 智能行程规划
- 输入项：目的地、出行日期（天数）、预算、人数、偏好（如美食/亲子/动漫）。
- 结果内容：
  - 日程安排：每日推荐景点与路线，适配同行偏好与强度。
  - 交通与住宿：建议交通方式与酒店位置（含大致预算范围）。
  - 餐饮与体验：餐厅与特色活动建议，避免“踩雷”。
- 交互：可在地图上查看各地点位置并发起导航；支持对行程进行删除/替换/重排。

### 4.2 费用预算与管理
- 预算分析：根据行程建议估算交通、住宿、餐饮与门票等费用。
- 记录方式：支持语音输入“午餐 120 元”，或文字录入；自动归类到相应科目。
- 统计视图：显示已花费、剩余预算与分类饼图/折线图。

### 4.3 用户管理与数据存储
- 注册登录：用于跨设备保存多份旅行计划与偏好设置。
- 云端同步：行程、偏好与费用记录同步至云端（例如 Supabase/Firebase）。
- 数据隐私：仅保存与旅行规划相关的必要信息；支持账号删除与数据导出。

### 4.4 地图与导航
- 地图服务：优先支持高德或百度地图 API（以所在地区可用性为准）。
- 位置权限：可选择允许定位以提供就近推荐与导航路线。
- 交互方式：在行程日程表中点击地点即可在地图上定位并发起导航。

## 5. 语音输入使用指引
- 首次使用会请求麦克风权限，请选择“允许”。
- 语音范例：
  - “我想去日本，5 天，预算 1 万，喜欢美食和动漫，带孩子。”
  - “记一笔晚餐 150 元。”
- 识别失败时：
  - 检查网络与麦克风设备。
  - 语句尽量完整清晰，避免强噪音环境。
  - 可改用文字输入。

## 6. 常见问题（FAQ）
- 无法加载地图？请检查网络并确认 API Key 设置正确；如仍失败，切换至备用地图服务或稍后重试。
- 语音识别不准？可在设置中切换识别引擎（如科大讯飞/浏览器原生），或改用文字输入。
- 云端同步失败？请重新登录并检查网络；确认所选云服务状态正常。
- 预算与实际不符？预算为估算，请根据实际更改分类与金额以保持准确。

## 7. 隐私与安全
- 仅在获得授权后访问麦克风与位置信息。
- 行程与费用数据仅用于功能实现，不对外共享。
- 提供数据导出与账号删除选项。

## 8. 技术栈（建议）
- 语音识别：科大讯飞或浏览器 Web Speech API。
- 地图导航：高德地图/百度地图。
- 数据库与认证：Supabase 或 Firebase Authentication + Firestore。
- 行程与预算：基于大语言模型 API 生成与估算。
- 前端框架：React + TypeScript（原型阶段）。
