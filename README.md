# Web 版 AI 旅行规划师（AI Travel Planner）

本项目旨在通过 AI 简化旅行规划流程，提供语音/文字输入的智能行程生成、预算记录与分析、用户登录与云端同步，以及基于地图的交互式行程展示。

## 功能概览
- 智能行程规划：输入目的地、日期、预算、人数与偏好，自动生成每日路线与建议。
- 费用预算与管理：支持语音/文字记录开销，显示预算占用与分类统计。
- 用户与云端：注册登录，多设备云端同步（如 Supabase/Firebase）。
- 地图交互：高德/百度地图显示地点、路线与导航。
